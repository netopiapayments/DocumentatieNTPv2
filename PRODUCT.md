# Produs

Ghidul de integrare NETOPIA Payments API v2, în format web, cu exemple care pot fi rulate în Sandbox.

**Pentru:** dezvoltatorii comercianților, agenții și integratori, echipa de implementare NETOPIA.

**Scop:** prima plată reușită în Sandbox cât mai repede, cu mai puține întrebări către echipa de implementare.

**Reguli:**
- Conținutul se editează doar în `API Ghid de Integrare.md`.
- Site-ul apelează doar Sandbox; credențialele rămân în browser.
